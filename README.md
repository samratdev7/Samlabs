# Samlabs

Samlabs is a small playground repository for experiments, ideas, and iterative improvements.

## Why this repository

- Keep work simple and approachable
- Ship improvements in small, focused steps
- Make collaboration clear for new contributors

## Getting started

1. Clone the repository
2. Create a branch for your change
3. Open a pull request with a short, clear summary

## Contributing

Contributions are welcome. Prefer minimal, targeted changes and include concise context in your pull request so reviews are fast and productive.
